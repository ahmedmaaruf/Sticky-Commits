    Put your sticker on the wall

    It's the real GitHub workflow — the same one open-source projects use every day.

    1. 🍴

      Fork

      Hit Fork on the repo to get your own copy.

    2. 📁

      Make a folder

      On a new branch, copy cards/_template to cards/<your-username>/.

    3. 🎨

      Make it yours

      Edit card.json — shape, finish, colours, font, picture — and preview it with npm run dev.

    4. 🚀

      Pull request

      Open a PR. A bot checks your sticker — once it's merged, it slaps onto the wall and enters the contest! 🏆

    Every option you can use is listed in CONTRIBUTING.md ✨

    ~/sticker-wall — zsh
    # the command-line way 🧑‍💻
$ git clone https://github.com/YOU/REPO.git
$ cd REPO && git switch -c add-my-sticker
$ cp -r cards/_template cards/YOU   # your GitHub username, lowercase
$ code cards/YOU/card.json          # make it yours ✨
$ npm run dev                          # preview at localhost:5173
$ git add cards/YOU
$ git commit -m "Add my sticker ✨"
$ git push -u origin add-my-sticker   # then open a Pull Request 🎉
