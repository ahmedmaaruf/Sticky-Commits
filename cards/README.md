# 🧩 Sticker folders live here

Make a folder named after **your GitHub username (lowercase)** and put your `card.json` inside:

```
cards/
  your-username/
    card.json      ← required (copy _template/card.json and make it yours)
    photo.png      ← optional picture
    style.css      ← optional custom CSS
```

Copy `_template/card.json` to get started. Full guide: [CONTRIBUTING.md](../CONTRIBUTING.md).
